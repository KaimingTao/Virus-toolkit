1) Study identity and scope

Study title / short name

Virus: species, strain/isolate, taxonomy version used

Primary question: surveillance, pathogenesis, transmission, therapeutics, vaccine, diagnostics, evolution, etc.

Study type: in vitro, animal, human observational, human interventional, environmental, computational

Primary endpoints + success criteria (pre-defined)

Versioning: protocol version, deviations log, change control owner

2) Ethics, biosafety, and compliance

Ethics approvals: IRB/IACUC/other; consent/assent; data privacy

Biosafety level: BSL-2/3/4 justification; training records

Risk assessment: agent hazards, aerosol procedures, sharps, waste

Select agent / export control checks (if applicable)

Dual-use review (documented)

Incident reporting + mitigation plan

3) Specimen / sample metadata (minimum information)

For every sample:

Unique sample ID (no re-use; barcode recommended)

Host: species, age, sex, relevant clinical status; vaccination/treatment history

Collection context: location (coarse), setting (clinic/community/lab), date/time, symptoms, exposure

Specimen type: swab type, blood fraction, tissue, wastewater, etc.

Collection method: kit, transport medium, volume, operator

Cold chain: time-to-freeze, storage temp, freeze-thaw count

Inclusion/exclusion criteria and missingness reasons

4) Controls and comparators (must define up front)

Negative controls: extraction blanks, no-template controls, mock-infected

Positive controls: quantified standard, cultured isolate, synthetic RNA/DNA

Internal controls: spike-ins, host gene controls, process controls

Batch controls: per-plate/per-run requirements

Comparator arms: reference assay, gold standard, baseline strain, etc.

5) Virus material characterization (if using isolates/constructs)

Provenance: source lab, passage history, cell line used, passage number

Identity confirmation: sequencing confirmation criteria

Titering method: PFU/TCID50/genome copies; calibration approach

Mycoplasma/contamination checks

Storage: aliquot size, additives, stability testing

6) Experimental design and statistics

Randomization method and allocation concealment

Blinding: who is blinded to what, and when unblinded

Power / sample size calculation and assumptions

Replication: biological vs technical replicates, minimum numbers

Pre-registered analysis plan (even internal): primary model, covariates, exclusions

Handling outliers, missing data, batch effects

Multiplicity correction strategy when many endpoints

7) Assay standards (general)

For each assay, specify:

Assay name + purpose (diagnostic, quant, functional)

SOP reference and instrument model + software version

Reagents: vendor, catalog, lot, expiry; storage conditions

Acceptance criteria: QC thresholds, rerun rules

Limits: LOD/LOQ, linear range, saturation behavior

Precision: intra/inter-run CV targets

Inter-lab comparability: calibration materials + proficiency testing plan

8) Molecular detection (qPCR/RT-qPCR/ddPCR)

Primer/probe sequences or references; amplicon target region and rationale

Reverse transcription conditions (if applicable)

Standard curve materials and traceability

Ct calling rules / baseline settings

Inhibition checks and corrective action

Reporting: copies per mL (or per swab) with uncertainty, not just Ct

9) Sequencing (WGS/amplicon/metagenomics)

Library prep kit + modifications

Input amount and QC thresholds (RIN, DV200, etc. where relevant)

Read platform + chemistry, run metrics targets (Q30, yield)

Coverage requirements: breadth/depth minimums; dropout handling

Bioinformatics:

reference and version

aligner/caller versions and parameters

contamination screening approach

lineage/clade assignment tool + version

Consensus rules: ambiguity thresholds, masking policy

Submission package: raw reads + consensus + metadata schema

10) Virology functional assays

Culture / isolation

Cell line authentication, passage limits

MOI definitions and verification

Cytopathic effect scoring rubric

Confirmation methods for successful isolation

Neutralization

Live virus vs pseudovirus, reporter system

Serum handling (heat inactivation, storage)

Curve fitting method; IC50/ID50 definitions

Reference sera and international standards if available

Entry / replication / fitness

Timepoints and readouts standardized

Normalization strategy

Competitive fitness assay design (if used)

11) Clinical data elements (if human studies)

Case definitions, severity scale used, symptom onset date

Comorbidities list and coding system (ICD/SNOMED)

Medications, antivirals, immunomodulators (dose/timing)

Outcome definitions (hospitalization, ICU, mortality, viral clearance)

Specimen–clinical timeline linkage rules

De-identification and recontact policy

12) Animal model standards (if applicable)

Species/strain/sex/age; housing and diet

Challenge dose, route, and justification

Humane endpoints; scoring system

Tissue collection plan and randomization

Reporting per ARRIVE-style checklist

13) Data management, provenance, and reproducibility

Data dictionary: required/optional fields + controlled vocabularies

Identifiers: sample IDs, subject IDs, run IDs, batch IDs

Provenance: who/when/how each transformation happened

Reproducible pipelines: containers, workflow manager, pinned versions

Audit trails for edits and corrections

Access control and retention periods

14) Quality assurance program

QC dashboard metrics (failure rates, batch drift, contamination flags)

Proficiency testing schedule (internal + external)

Inter-lab ring trials plan

Corrective/preventive actions (CAPA) workflow

Periodic protocol review cadence

15) Reporting standard (minimum reporting checklist)

Protocol + deviations

Full methods with enough detail to reproduce

All QC metrics and failures (not just successes)

Uncertainty estimates (CI, credible intervals)

Data and code availability statements

Clear limitations section tied to design/assays

16) Data sharing and submission

Deposition targets: sequence repositories, assay datasets, clinical metadata (where allowed)

Timing: at publication / rolling release / embargo rules

Metadata schema compliance checks

Licensing terms and reuse constraints

Contact point for corrections

17) Terminology and controlled vocabularies

Standard names for specimen types, anatomical sites, assay types

Units normalization (copies/mL, PFU/mL, TCID50/mL)

Variant/lineage naming conventions + tool/version requirement

Time variables (onset day 0, collection day, treatment day)

18) Security and sensitive information handling

Redaction policy for locations/dates where needed

Access tiers (public, consortium, restricted)

Safe release review for sensitive methods/data

19) Governance of the standard

Scope boundaries (what’s in/out)

Working group roles

Versioning policy (semantic versioning recommended)

Change proposal template + review timeline

Compliance levels: “Required / Recommended / Optional”

Conformance testing (what “passes”)

20) Appendices you can include

A) Minimal metadata schema (CSV/JSON template)

B) SOP index and required fields per SOP

C) QC thresholds table per assay

D) Standard operating definitions (LOD/LOQ, positivity, failure)

E) Example methods section boilerplate
